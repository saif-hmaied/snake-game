Snake Game

Browser demo of the C console game. Same board, same rules, same French menu.

C:\snake-game\main.exe
Controls (AZERTY layout, like the original; arrow keys work too)
z / ↑Move up
s / ↓Move down
q / ←Move left
d / →Move right
a / EscSave and return to the menu
Each + adds one segment and 10 points. Hitting a wall or your own body ends the game. The save and best score are kept in your browser.
